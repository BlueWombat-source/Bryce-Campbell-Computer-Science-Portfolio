CS 499 Capstone: Enhanced Mobile Fitness Tracker
This project is an enhanced version of the mobile weight‑tracking application originally developed in CS‑360: Mobile Architecture and Programming. The goal of the CS‑499 Capstone was to evolve the existing artifact by improving it across three core computer science domains: Software Design & Engineering, Algorithms & Data Structures, and Databases. These enhancements demonstrate growth throughout the Computer Science program and reflect industry‑aligned engineering practices.

📱 Project Overview
The original application allowed users to log their weight, set a goal, and receive a notification upon reaching that goal. The enhanced version expands the app into a more comprehensive fitness‑tracking tool with improved functionality, deeper technical complexity, and a more scalable architecture.

🛠️ Software Design & Engineering Enhancements
- Implemented a Basal Metabolic Rate (BMR) calculator to help users estimate daily caloric needs.

- Built a workout planner and logging system, allowing users to:

- Create custom workout routines

- Log sets, reps, resistance, and duration

- Track performance over time

- Improved UI flow and modularized code for better maintainability and readability.

📊 Algorithms & Data Structures Enhancements
Designed structured SQL tables to store:

- Exercises

- Workout routines

- Logged workout sessions

- Performance metrics

- Introduced more complex data relationships to support efficient retrieval and organization.

- Enhanced algorithmic logic for:

- Calculating BMR

- Generating progress visualizations

- Managing workout data structures

🗄️ Database Enhancements

- Expanded the database schema to support richer fitness‑related data.

- Added relational tables for workouts, exercises, and logs.

- Improved query efficiency and data normalization.

- Prepared the architecture for future enhancements such as:

- Additional fitness metrics

- Potential integration with external data sources

- More advanced analytics

🎯 Capstone Purpose
These enhancements transform the original simple weight‑tracking app into a more robust, feature‑rich fitness companion. The project demonstrates proficiency in full‑stack mobile development, structured data design, and scalable software engineering, aligning with the CS‑499 outcomes and showcasing readiness for professional development work.
